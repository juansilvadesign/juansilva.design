# SYD Showcase Brief

A high-fidelity motion graphics showcase proving the three-audience, three-breakpoint responsive design and coding architecture of SYD (SaveYourDay).

## Persuasion Arc
1. **The Core Dilemma**: On-demand mental healthcare serves 3 fundamentally distinct audiences who cannot share one generic landing page.
2. **The Patient Experience (1440px Desktop)**: Urgency, emotional safety, instant booking.
3. **Responsive Continuity (1440 → 1280 → 375)**: Fluid layout adaptation across breakpoints built by the same designer-engineer without handoff loss.
4. **The Supply Side (Profissional)**: Recruitment, scheduling control, fair pay-by-minute model.
5. **The Enterprise Solution (RH)**: Frictionless corporate wellness, usage metrics, productivity protection.
6. **Unified Resolution**: The 9-state responsive matrix resolves together into an elegant closing composition that seamlessly loops.
